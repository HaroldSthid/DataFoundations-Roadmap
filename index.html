Ruta sugerida

La curva de aprendizaje se adapta al ritmo de cada equipo, pero la progresión de fondo es siempre la misma: del dato crudo al dashboard, pasando por fundamentos, arquitectura y algoritmos.

1

Onboarding / Contexto

Panorama laboral, habilidades en demanda, impacto de la IA en el sector tech. Se define la ruta y el ambiente de trabajo (PC con Windows recomendado, Mac también funciona).

2

Fundamentals & Essentials

Excel → SQL (SQLite) → Python (Google Colab). Diseño de modelo ERM, poblamiento con datos sintéticos, data cleaning y primeras queries de reporting.

📍 Estás acá — ver repo Fundamentals-BaseDatos-SQLite

3

ETLs & Elementos de Arquitectura

DBeaver como gestor de bases de datos, Power BI para consumo de datos. Se formaliza el paso de datos locales a procesos repetibles.

Spatial Analysis & Avanzado

Web scraping, UX y segmentación aplicados sobre el dataset del proyecto principal.

Recursos mapeados

Poblamiento de datos sintéticos

  • Mockaroo — esquemas complejos, export directo a CSV/SQL.
  • GenerateData — alternativa open source para grandes volúmenes.
  • Faker (Python) — librería estándar de la industria para datos de prueba.
  • Mimesis — alternativa ultra rápida en Python.

Diseño y gestión de bases de datos

  • dbdiagram.io — diagramar el modelo ERM visualmente.
  • DBeaver — Database Manager open source, multi-motor.
  • Documentación oficial SQLite

Playground SQL

Motor SQLite corriendo 100% en tu navegador (sql.js, SQLite compilado a WebAssembly). No hay backend ni instalación: se precarga el mismo modelo clientes / productos / ventas de la sesión de arquitectura para que practiques queries ahí mismo.

Esquema precargado:

clientes(id, nombre, ciudad)
productos(id, nombre, precio)
ventas(id, cliente_id, producto_id, cantidad)
